# Team Task Manager & Project Dashboard

This repository contains a production-grade Project Management Dashboard web application.

- **`task-management/`**: React 19 + TypeScript + Redux Toolkit + Vite Frontend Web Application.
- **`task-managemnet-BE/`**: Optional Express.js + MongoDB backend.

## Quick Start (Frontend out-of-the-box)

```bash
cd task-management
npm install
npm run dev
```

Visit `http://localhost:5173` to test the application!

For full architectural overview, testing guide, and documentation, refer to [`task-management/README.md`](./task-management/README.md).
